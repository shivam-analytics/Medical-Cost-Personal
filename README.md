# Medical Insurance Cost Analysis

A Power BI project that explores the factors influencing personal medical insurance charges. The analysis uses demographic, lifestyle, family, and geographic information to identify patterns in healthcare costs.

## Project Overview

Medical insurance charges can vary significantly based on age, BMI, smoking habits, number of dependents, and region. This project turns the insurance dataset into an interactive Power BI dashboard and a supporting analysis report.

### Questions explored

- How do medical charges change with age and BMI?
- How strongly does smoking status affect insurance costs?
- Which regions have higher or lower average charges?
- How do family dependents influence total medical expenses?
- Which customer segments are associated with the highest charges?

## Dataset

The dataset contains personal and insurance-related records with the following fields:

| Column | Description |
| --- | --- |
| `age` | Age of the insured person |
| `sex` | Sex of the insured person |
| `bmi` | Body Mass Index |
| `children` | Number of dependents/children covered |
| `smoker` | Smoking status (`yes` or `no`) |
| `region` | Residential region in the United States |
| `charges` | Medical insurance charges |

## Suggested Analysis Flow

1. Review overall medical charges and the distribution of customer characteristics.
2. Compare average charges between smokers and non-smokers.
3. Examine the relationship between age, BMI, and charges.
4. Compare regional and family-size differences.
5. Use the dashboard findings to identify high-cost customer segments.

## Key Takeaway

The project is designed to make medical insurance cost patterns easier to understand through interactive visual analysis. It can support exploratory research, business reporting, and further predictive modelling of insurance charges.
